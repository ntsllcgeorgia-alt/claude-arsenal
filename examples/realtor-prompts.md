# 20 Copy-Paste Prompts for Realtors

Open this file, find the situation, edit the brackets, paste into Claude Code. Don't overthink it — Claude figures out which skill to fire.

If a prompt assumes a service you haven't set up yet (Higgsfield, Late, Firecrawl), Claude will tell you what's missing.

---

## Section 1: Listings

### 1. Write a listing description

```
Write a 250-word listing description for [123 Maple St., Madison WI].
4-bed, 2.5-bath colonial. 2,400 sqft. .4 acre lot. Privacy fence.
Finished basement with home office. Detached 2-car garage.
Buyer profile: remote-work couple, one kid, dog.
Lean into: privacy, the basement office, the dog-friendly yard.
Avoid: 'cozy', 'charming', 'must-see', 'won't last'.
```

### 2. Generate a hero image for the listing page

```
Generate a hero image for my new listing landing page.
Reference photos (drag URLs into the chat): [paste 1-3 URLs]
Style: golden-hour exterior, warm light through the windows,
shallow depth of field, lifestyle/aspirational.
Aspect ratio: 16:9.
```

### 3. Build a single-listing landing page

```
Design a single-listing landing page for [123 Maple St].
Sections: hero / 3 reasons to buy in this neighborhood / video tour /
walkthrough photos / map / lead capture form.
One CTA: 'Schedule a private showing'.
Buyer profile: young families relocating to the school district.
```

### 4. Make a 15-second video tour

```
Make a 15-second cinematic walkthrough video of [123 Maple St].
Reference photos: [paste 3 URLs]
Vibe: golden hour, slow camera moves, indie-folk music.
End with overlay: 'Open house Saturday 1-3pm.'
Output: 9:16 (Reels/TikTok), 1:1 (IG feed), 16:9 (YouTube).
```

### 5. Make a UGC testimonial video

```
Make a UGC-style testimonial video.
Script: "[paste verbatim client quote]"
Style: phone-shot, natural light, [age/gender/setting].
Format: 9:16, 30 seconds.
```

## Section 2: Lead generation

### 6. Cold email to FSBO sellers

```
Use cold-email agent.
Prospect: [Owner name] selling [address] FSBO since [date].
Listed at $[price]. Comps suggest $[range].
Listed [N] days. About 1 showing/week.
Their pain: probably showings + paperwork burnout, not commission.
Output: 3 lines + 6-word subject.
```

### 7. Pre-listing-appointment brief

```
Use lead-researcher.
Prospects: [Name and Name], [address].
Bought [year] for $[price]. Zestimate now ~$[value].
[One known fact: kid graduating, job change, divorce, etc.]
Listing appointment tomorrow at [time].
```

### 8. Find prospect signals in a zip code

```
Help me find prospect signals in zip code [53703].
Look at: marriage announcements, retirement news, kids' college acceptances,
job changes to other states, expired listings 180+ days off market,
LLC absent-owner transfers.
Rank by likelihood of selling in the next 90 days.
```

### 9. Buyer consultation prep

```
Use lead-researcher.
Prospect: [Name and Name], currently renting at $[rent]/mo in [neighborhood].
Pre-approved for $[amount].
Looking at homes in [target neighborhoods].
First meeting tomorrow at [time]. I need to walk in knowing what they actually want vs what they think they want.
```

### 10. Diagnose why a prospect isn't moving

```
Apply switching-forces analysis to this prospect.
[Name and Name]. Renting at $[rent]/mo. Saved $[amount] for down payment.
We've looked at [N] houses in [N weeks]. They said "we love it" twice
but pulled back at offer stage.
What's the Push, Pull, Habit, Anxiety? Where are they actually stuck?
And what should I say next?
```

## Section 3: Social media

### 11. Plan a week of social posts

```
Plan and write 7 social media posts for me, one per day this week.
Mix: 2 listing posts / 2 educational / 1 behind-the-scenes / 1 market update / 1 client win.
Each post: IG caption + LinkedIn version + hero image.
Schedule via Late for 9am posting Mon-Sun.
```

### 12. Carousel about local market

```
Make a 5-slide Instagram carousel: '[topic — e.g., 5 things first-time buyers in Wisconsin miss]'.
Slides:
  1. Cover (hook)
  2-5. [list the 4 points]
  6. CTA: 'DM me "guide" for the full PDF'
Style: clean, editorial, [palette]. Square 1:1.
```

### 13. Post a Reel + Short + TikTok of a property

```
Post this video as short-form to YouTube Shorts, IG Reels, and TikTok.
Video: [absolute path to your video file]
Property: [brief description].
Make platform-specific titles + captions + hashtags.
Do NOT post until I approve the package.
```

### 14. Audit your existing social media

```
Use content-audit.
My Instagram handle: @[handle].
Audit my last 50 posts.
Output: top 5 patterns that drove engagement + a playbook for next quarter.
```

## Section 5: Website + marketing

### 16. Audit your landing page for conversion

```
Audit my landing page for conversion.
URL: [your URL]
Goal: [what action you want visitors to take]
Tell me the top 5 reasons people aren't converting, ranked by impact,
and the exact change to make for each.
```

### 17. Build a personal agent website

```
Design a personal website for me.
About: [your niche, e.g., 'Madison WI buyer's agent specializing in Chicago relocations']
Sections: hero / about / how I work / 3 case studies / 4 testimonials / lead capture
Style: modern, warm, editorial.
Personal but not amateur.
```

### 18. Build a marketing brain (do this ONCE, then forget it)

```
Build a MARKETING.md file for my real estate business.
Niche: [your niche]
ICP: [age, income, household composition]
Pain points: [top 3]
Differentiator: [what makes you different]
Voice: [warm/direct/playful/formal — pick one]
Proof: [number of recent wins, awards, years experience]
```

Run this once. Every other marketing skill reads it automatically from then on.

### 19. Triage your inbox

```
Use inbox-hawk.
Surface only what needs me TODAY across all my inboxes.
Max 7 items. Don't draft replies.
```

### 20. End a long Claude session cleanly

```
/handoff
```

(That's it. The handoff skill generates a "restart prompt" you can paste into a fresh Claude chat — preserves context without burning tokens by re-reading the whole conversation.)

## The meta-prompt: when nothing here fits

```
/find-skills
I want to [describe the situation in plain English].
```

This searches the registry. If a matching skill exists, Claude tells you. If not, it asks if you want to build a new one with `skill-creator`.

---

**Pro move:** Save your favorite versions of these prompts in your phone notes app. When you're driving back from a showing and have an idea — voice-to-text it and shoot it into Claude when you're back at your desk.
